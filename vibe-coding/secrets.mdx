Some apps need a sensitive value: an API key, a token, a password. You set these through a **one-time form** in the mogenius UI, so the value goes straight into your app without passing through the conversation.

## How it works

<Steps>
  <Step title="Ask your agent to add a secret">
    Tell the agent your app needs a secret — for example *"this app needs an API key called `OPENAI_API_KEY`."* The agent registers it and gives you a **one-time link**.
  </Step>
  <Step title="Open the link and enter the value">
    The link opens a small form for that one secret. Enter the value and submit — it's stored directly as the app's secret.
  </Step>
  <Step title="The app gets it on the next deploy">
    The value is made available to the app under the name you chose. The agent's code reads it by name; it never sees the value itself.
  </Step>
</Steps>

To change a secret later, ask the agent for a new link and enter the new value.

<Note>
Your agent and your app's code only ever know a secret's **name**, never its content. Secrets apply to an app's [preview](/vibe-coding/app-capabilities#previews) too.
</Note>
